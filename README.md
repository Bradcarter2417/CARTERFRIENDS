# CARTERFRIENDS

A premium social platform concept for meeting people, sharing photos and videos, watching reels, going live, and browsing a marketplace.

## Run locally

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm start
```

Then visit http://localhost:3000

## Deploy

This project includes a Render deployment config in [render.yaml](render.yaml).

1. Push the repo to GitHub.
2. Create a new Web Service on Render.
3. Connect the repo and use the existing config.
4. Render will run `npm install` and `npm start` automatically.
